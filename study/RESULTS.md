# Results

Generated by `study/report.py` from `study/results/summary.json`. Protocol: [PROTOCOL.md](PROTOCOL.md). Questions: [questions/questions.json](questions/questions.json). Every response: `study/runs/`.

**Snapshot** = exactly the reference rows on the repository's database. **Suite** (called *robust* elsewhere) = the same query also returns the reference rows on all eight counterfactual copies of that database, which catches many queries that are right on one database by coincidence. Each cell is the mean over repetitions, with the lowest and highest in brackets.

**Evaluator.** These scores use the corrected references ([corrections](questions/corrections.json), [protocol](PROTOCOL.md#corrections-after-the-runs)): 21 reference queries that missed a restriction stated in their question were corrected after the runs, and 5 questions accept either of two readings. Snapshot scores are identical under both versions. The scores under the frozen references, as first published, are in [results/frozen/](results/frozen/RESULTS.md) and compared below.

## Validity

- Every reference reading runs on the real database and all eight counterfactual databases, and no corrected reference changes its answer on a real database (`python study/check_references.py`, [reference_check.json](results/reference_check.json)).
- Rescoring with the frozen references reproduces the published frozen scores exactly; rescoring them on the regenerated counterfactual databases changes no score.
- The reference answer changes on at least one counterfactual database for 44 of 48 questions; for ao-09, click-10, httpx-10, rich-05 the reference answer never changes, which limits the suite's ability to catch a fixed answer there.
- 48 of 48 author–annotator agreements before rewording; 17 questions reworded, none removed ([adjudication](questions/adjudication.md)). The authors and annotators were AI models working under the protocol, not the repositories' maintainers.
- Discarded runs: [results/discarded.md](results/discarded.md).

## Reproduce

Rescoring needs no model calls. Build the databases (`sh study/build_data.sh`), then:

```sh
for r in auto_ontology click httpx rich; do python study/fuzz.py $r build/study/fuzz-corrected --variants 8 --seed 0; done
python study/check_references.py
python study/summarise.py --evaluator corrected
python study/report.py
```

`python study/summarise.py --evaluator frozen --fuzz-dir build/study/fuzz-corrected --out <dir>` reproduces `results/frozen/` exactly. The scorer refuses to report a suite score unless all eight counterfactual databases are present, and records each database's SHA-256 in `scores.json`. Rerunning the models is described in [PROTOCOL.md](PROTOCOL.md).
